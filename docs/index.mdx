PolyBot turns your Telegram bot logic into clean, attribute-decorated handler methods. A Roslyn source generator compiles them at build time into a hard-coded, optimized `BotRouter` — no reflection, no runtime overhead, and full dependency injection out of the box.

## Why PolyBot?

Traditional `Telegram.Bot` bots require a central `HandleUpdateAsync` with nested `switch` statements over `Update.Type`. PolyBot eliminates that entirely — you write one handler method per intent, and the framework wires everything up at compile time.

<CardGroup cols={3}>
  <Card title="Source-Generated Router" icon="wand-magic-sparkles">
    Roslyn generates a `BotRouter` from your handler attributes at compile time. Zero reflection at runtime.
  </Card>
  <Card title="Full DI Support" icon="cubes">
    Handler parameters resolve automatically from the service container — inject anything from `ITelegramBotClient` to your own services.
  </Card>
  <Card title="Finite State Machines" icon="diagram-project">
    Built-in FSM support with `[State<TEnum>]` and pluggable `IStateStorage` for multi-step conversations.
  </Card>
  <Card title="Inline Awaits" icon="pause">
    Suspend a handler mid-conversation and resume when the next matching update arrives — without blocking the polling loop.
  </Card>
  <Card title="Callback Patterns" icon="route">
    Route callback queries by template: `[Pattern("item:{id}:{action}")]` with typed `[Arg]` extraction.
  </Card>
  <Card title="Built-in Testing" icon="flask">
    Token-free in-memory test harness via `UpdateMocker` — no network, no real bot token needed.
  </Card>
</CardGroup>

## Get Started

<Steps>
  <Step title="Install the NuGet package">
    Add `PolyBot` to your .NET project. The source generator is bundled as an analyzer.

    ```bash
    dotnet add package PolyBot
    ```
  </Step>
  <Step title="Write your first handler">
    Decorate a static method with a handler attribute and return `Result`.

    ```csharp Program.cs
    using PolyBot.Attributes;
    using PolyBot.Routing;
    using Telegram.Bot.Types;

    public sealed partial class BotHandlers
    {
        [MessageHandler]
        [Command(Aliases = ["start"], Description = "Start the bot")]
        public static async Task<Result> Start(Message msg, ITelegramBotClient bot, CancellationToken ct)
        {
            await bot.SendMessage(msg.Chat.Id, "Hello from PolyBot!", cancellationToken: ct);
            return Result.Handled();
        }
    }
    ```
  </Step>
  <Step title="Register and run">
    Create a `PolyBotClient`, register the generated router, and start polling.

    ```csharp Program.cs
    using PolyBot;

    PolyBotClient client = new PolyBotClient(new PolyBotOptions { BotToken = "<your-token>" });
    client.Services.AddPolyBotRouter(); // generated by the source generator
    await client.RunPollingAsync();
    ```
  </Step>
</Steps>

<Note>
  `AddPolyBotRouter()` is generated at compile time by the PolyBot source generator — it will appear after your first build. See [Installation](/installation) for project setup details.
</Note>
